### Focus & Projects

- **Hardware Repair & Digicams NYC:** Through [digicamsnyc.com](https://digicamsnyc.com), I track down broken vintage digital cameras, diagnose flex cables and power rails, repair shutter mechanisms, and bring classic CCD sensors back to life.
- **Self-Hosting & Homelab:** I run a private bare-metal homelab cluster alongside offsite VPS instances. High-level focus on media storage (self-hosted Immich), home automation, and containerized internal web services.
- **Web Development:** Modern, high-performance web applications using TypeScript, component-driven UI, and clean design patterns.
